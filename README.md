# CASE 1021 — VS Code用ミステリーゲーム（改訂版 v2）

## 起動方法
1. このフォルダを VS Code で開きます。
2. `index.html` を Live Server で開きます。ブラウザで直接開いても動作しますが、保存を安定させるには Live Server をおすすめします。
3. `index.html`、`style.css`、`script.js` を必ず同じフォルダに置いてください。

## 公開時刻（日本時間）
- **2026年10月21日 10:00**：導入／3つの同封資料／最初の推理まで。
- **2026年10月21日 17:00**：追加資料／記録1020／人物AとBの推理／暗号／最終報告まで。
- 最後まで進んでも、匿名の依頼人の正体や現実で起こることはゲーム内では明かしません。

公開時刻より早く17時以降の場面へ進む操作には、コード内でガードを設けています。すでに閲覧した場面に戻ったり、戻った先から閲覧済みの場面へ進むことは可能です。**未公開の場面には進めません**。ただしこれは静的サイトのブラウザ時計を使った判定です。閲覧者が時計やJavaScriptを変更すれば回避できるため、強力なアクセス制限ではありません。強制的な未公開管理が必要な場合は、10時版と17時版を別々にサーバーへ公開する必要があります。

## 制作者用の全編プレビュー
Live Server で開いた URL に `?preview=1` を付けてください。

例：`http://127.0.0.1:5500/index.html?preview=1`

**送る相手には `?preview=1` を含まない通常のURLを渡してください。** これはソースに実装された確認用モードで、アクセス制御の代用にはなりません。

## v2で追加・変更したこと
### 1. 左側に証拠が蓄積
- 開いた資料だけが左側の **COLLECTED EVIDENCE** に追加されます。
- 依頼書、人物Bの記録、六組の暗号、追加報告、人物Aの資料、原稿、推理メモなどが段階的に増えます。
- 左側の資料をクリックすると、**今いる場面を変えずに**重ねて資料を開けます。閉じると元の場面へ戻ります。
- スマホでは「収集した証拠を開く」をタップすると一覧が展開します。

### 2. 戻る・進む・調査履歴
- 本文上部の「← 戻る」「進む →」で閲覧済みの場面を行き来できます。
- 左側の「これまでの調査履歴」から閲覧済みの場面へ移動することもできます。
- 調査履歴は**未訪問の場面を先読みする機能ではありません**。操作により初めて解除する場面へ進むには、従来の資料確認・推理などを済ませる必要があります。

### 3. 暗号のヒントを段階式に
- 暗号画面に五十音表や変換例を最初から表示しません。
- 画面には六組の数字と依頼人の短い書き込みだけを表示します。
- 解けない場合は「捜査メモ」を任意で1段階ずつ見ることができます。最後の段階で初めて解き方の方向性が強く示されます。表そのものは自動表示されません。

### 4. セーブデータ
- `localStorage` で進行場面、開いた証拠、ヒントの閲覧、調査履歴を保存します。
- 以前の `case1021-save-v1` の保存記録からも可能な範囲で自動移行します。
- 同じブラウザと同じURLの保存領域で続きを再開できます（別端末・別ブラウザでは共有されません）。
- フッター「調査記録を初期化」で最初からやり直せます。

## GitHub Pagesで公開する場合
1. 新しいGitHubリポジトリを用意する。
2. `index.html` `style.css` `script.js` をルートにアップロードする。
3. Settings → Pages → Build and deployment で `main` / `/ (root)` から公開する。
4. iPhoneのSafariでも実際に表示・公開時刻をチェックする。
5. 彼氏に渡すURLは `?preview=1` のないものにする。

## 編集の目印
- 公開時刻：`script.js` 冒頭の `START_AT` / `SECOND_AT`
- 物語と問題：`sceneOpening()` ～ `sceneFinal()`
- 暗号のヒント：`cipherHints` と `sceneCipher()`
- 左の証拠一覧：`evidenceCatalog` と `renderSidebar()`
- 移動・制限：`go()`、`canEnter()`、`sceneNavigation()`
- 配色・スマホ表示：`style.css`

動作に画像・外部ライブラリ・APIは不要です。
